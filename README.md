# Tutor

A mobile-friendly progression-path tutor app (React + TypeScript + Vite), deployed as a static site on GitHub Pages.

- Accounts (username + birth year) are stored in `localStorage` — no backend.
- Topics: French and English are placeholders; **Algebra** is fully implemented.
- Each topic is a Candy-Crush-style progression path of exercises, grouped by level.
- Exercise content lives in `public/content/<topic>/<level>/<n>_exercises.json`, indexed by `public/content/<topic>/manifest.json`.
- Scores (0-5) are stored per exercise UUID in `localStorage`.

## Develop

```bash
npm install
npm run dev
```

## Regenerate algebra content

`public/content/algebra/**` is generated by a script (deterministic, seeded):

```bash
node scripts/generate-content.mjs
```

## Editing an exercise by hand

`manifest.json` is a cached index the path screen reads to draw the whole progression
path without fetching every exercise file — it duplicates a few fields (`title`,
`evaluation`, `difficulty`, `character`) from each exercise's own JSON file. It does
**not** auto-follow edits to those files, so those fields would go stale otherwise.

`npm run dev` and `npm run build` resync every topic's manifest automatically
(`predev`/`prebuild` in `package.json`) before starting. That only runs once at
startup though — if your dev server is already running, rerun it manually to pick up
an edit without restarting:

```bash
node scripts/sync-manifest.mjs        # all topics
node scripts/sync-manifest.mjs algebra  # one topic
```

### The `character` field

An exercise can carry an optional mascot image shown next to its path node:

```json
"character": { "image": "characters/<file>.png", "position": "left" | "right" }
```

- Character images live under `public/characters/` (plain static files, not
  `src/assets`) so they're fetchable at runtime by a path coming from JSON data,
  the same way `content/**` is.
- `image` is a path relative to the site root, e.g. `characters/puzzledChicken.png`
  — no leading `/` or `../`.
- Omit the field (or set it to `null`) for exercises with no character.

## Deploy

Pushing to `main` builds and deploys to GitHub Pages via `.github/workflows/deploy.yml`.
Enable Pages once, in the repo settings, with source set to **GitHub Actions**.
